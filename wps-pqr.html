WPS, pWPS and WPQR/PQR: Document Roles and Control

The applicable code system must be identified before the documents are reviewed. ISO uses pWPS, WPS and WPQR; AWS uses WPS and PQR. Similar abbreviations do not make the qualification routes interchangeable.

Document sequence under the ISO procedure-test route

pWPS → qualification test weld → examination and testing → WPQR → production WPS

ISO 15609-1 specifies the content of an arc-welding WPS. ISO 15614-1 specifies one route for qualifying a preliminary WPS by a welding procedure test and defines the resulting range of qualification. The WPQR records the actual test conditions, examination and test results, and the range derived from the applicable qualification standard.

Function of each document

DocumentFunctionInformation that must remain traceable
pWPSInstructions used to produce the qualification test weldJoint preparation, parent materials, welding process, consumables, position, parameters and thermal controls
WPQR / PQRRecord of the qualification test and its resultsActual materials, actual welding variables, NDT, destructive tests, deviations and the calculated qualification range
WPSControlled instruction for production weldingPermitted values or ranges, sequence, consumable control, preheat, interpass temperature and any post-weld treatment

Actual values and permitted ranges

A qualification record must state the values actually used for the test weld. If the measured current was 245 A, recording a broad machine range such as 200–300 A does not describe the test. A production WPS can contain a range only where that range is supported by the governing qualification rules and remains technically suitable for the production joint.

Applicability to the production weld

A signed WPQR or PQR is not sufficient by itself. The production WPS must be checked against the qualified parent-material grouping, product form, thickness, deposited weld-metal thickness, pipe diameter where relevant, joint type, welding process, position, backing, consumables, heat input or arc-energy controls, preheat, interpass temperature and post-weld heat treatment. The comparison is made against the code edition stated in the contract.

ISO, GB/T and AWS are separate systems

ISO 15614-1 and AWS D1.1 use different qualification rules and terminology. AWS D1.1 also permits prequalified WPSs, but only when every applicable condition of that code is satisfied. An AWS prequalified WPS is not an ISO pWPS, and an ISO WPQR does not automatically qualify an AWS WPS.

For Chinese terminology, GB/T 19867.1-2005 uses “焊接工艺规程” for WPS, and GB/T 19869.1-2005 covers welding procedure qualification tests. Both remain current in China at the time of writing, but they adopt earlier ISO editions. They should not be treated as textually identical to ISO 15609-1:2019 or ISO 15614-1:2017+A1:2019.

Minimum document-control check

  1. Confirm the governing code, edition and qualification route.
  2. Match material certificates and consumable records to the qualification test piece.
  3. Verify that actual welding variables were recorded contemporaneously.
  4. Check that NDT, specimen locations and laboratory reports identify the same test weld.
  5. Derive the range of qualification from the applicable standard; do not copy it from an unrelated certificate.
  6. Issue the production WPS with a unique number, revision, approval status and link to the relevant WPQR/PQR.
The WPQR or PQR establishes qualification evidence. The WPS converts that evidence into controlled production instructions.
